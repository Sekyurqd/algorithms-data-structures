В Scratch блок «изменить [переменную] на [1]» находится в фиолетово-оранжевой вкладке «Переменные» (Variables).
По умолчанию на блоке написано изменить [моя переменная] на (1).
Чтобы настроить его для шага 3:
 * Кликни по выпадающему списку внутри блока (где написано «моя переменная»).
 * Выбери из списка свою переменную i.
 * В белом кружочке справа останется цифра 1.
Как выглядит вся конструкция внутри цикла (по порядку):
Все эти блоки вставляются внутрь оранжевой скобки повторить (n) раз:
 * задать [fact] значение ([fact] * [i]) — из вкладки Переменные + Операторы ()*
 * задать [F] значение ([F] * [fact]) — из вкладки Переменные + Операторы ()*
 * говорить (объединить [Шаг: ] (i)) 0.5 секунд — из вкладки Внешний вид + Операторы (объединить)
 * изменить [i] на (1) — из вкладки Переменные (самый нижний блок в цикле)
